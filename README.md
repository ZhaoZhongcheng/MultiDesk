> Windows 多虚拟桌面管理工具：每个桌面拥有**独立的桌面图标集合**和**独立壁纸**。
> 切换桌面时会隐藏其它桌面的窗口并恢复当前桌面的窗口，**程序进程继续运行**，不会中断你的工作。

*MultiDesk is a lightweight virtual-desktop manager for Windows written in **C# / WPF** on .NET Framework 4.8. It was developed with **AI assistance** — see the [AI-assisted development statement](#13-ai-辅助开发声明). Every virtual desktop keeps its own icons and wallpaper; switching desktops hides and restores windows without terminating any process. Download the latest build from [Releases](../../releases/latest).*

适用系统：Windows 10 / Windows 11（x64），需要 .NET Framework 4.8（Windows 10 1903+ 与 Windows 11 系统自带，无需另外安装）。

## 1. 功能特性

- **多个虚拟桌面**：可创建、重命名、排序、删除任意多个桌面（设置窗口左侧列表）。
- **每个桌面独立的桌面图标**：可在桌面图层上直接拖放图标、双击启动、拖入文件/文件夹添加图标；图标按栅格自动吸附、可整理对齐。图标集合保存在程序配置中，不会移动或删除你磁盘上的真实文件。
- **每个桌面独立的壁纸**：支持「跟随当前桌面壁纸（实时/动态壁纸）」「图片」和「纯色」三种模式，图片支持填充/适应/拉伸/居中/平铺。
- **实时壁纸（1.1.0）**：桌面图层是透明窗口，「跟随当前桌面壁纸」模式直接把系统真实桌面透出——Windows 壁纸和 **Wallpaper Engine 等壁纸软件渲染的动态壁纸都会实时可见**。
- **Windows 原生桌面右键菜单（1.1.0；1.2.0 起改为「更多选项」）**：最早把桌面空白处右键直接转发给系统桌面；1.2.0 起默认使用自绘功能菜单（见下一节），菜单末尾的「更多选项（Windows 原生菜单）…」仍可打开系统原生菜单（查看/排序方式/刷新/新建/显示设置/个性化/第三方扩展项）。
- **图标大小与排列（1.1.0）**：设置中可选小（32px）/中（48px）/大（64px）；可开关「自动排列（网格对齐）」，关闭后可自由摆放（允许重叠）；支持「整理图标」「按名称排序」。
- **双击启动窗口归属（1.1.0）**：在新桌面上通过图标启动程序时，新窗口或被激活的窗口会自动归属当前桌面，不会跑到旧桌面被隐藏（修复"新建桌面图标双击打不开"）。
- **受限启动自动回退（1.1.0）**：从聊天软件/沙箱/受限启动器启动（低完整性）时，自动回退为不透明系统壁纸 + 内置右键菜单，保证可用；从资源管理器双击启动可获得全部功能。
- **图标外观与 Windows 原桌面一致（1.2.0）**：默认读取真实 Windows 桌面的图标大小与网格间距（含不同 DPI 缩放），字体/行距/标签样式保持一致，不再比原桌面"更散更大"；设置中可切回自定义大小。
- **功能化桌面右键菜单（1.2.0）**：桌面空白处右键的「查看 / 排序方式 / 刷新 / 新建」只作用于**当前虚拟桌面**（图标大小、自动排列、显示桌面名称、按名称/类型/大小/日期排序、新建文件夹/文本文档都只加到当前桌面，不会修改真实桌面）；菜单末尾「更多选项」可打开 Windows 原生菜单使用第三方扩展。
- **切换桌面防闪烁（1.2.0）**：切换前先把桌面图层预渲染到目标桌面，再隐藏/恢复窗口，大幅减少切换时的窗口与图标闪烁。
- **启动更省心（1.2.0）**：发布包的快捷方式/启动 bat 通过普通权限启动（不弹 UAC、不触发 SmartScreen，也不会因"提权窗口在前台"导致其它程序的截图快捷键失效）；「受限启动」提示可在设置中关闭，且勾选一次"否"后不再打扰。
- **受限启动自动恢复完整功能（1.2.1）**：若之前在受限提示中选择过「否」（不再提示）且开启了「受限启动时自动以完整权限重启」（默认开启），下次从聊天软件/沙箱启动时会**直接弹出 Windows UAC 以完整权限重启**（只弹系统 UAC，不再弹程序自己的提示框）；取消 UAC 则静默回退受限模式。设置 →「常规设置」可关闭自动提权或重新开启受限提示。
- **托盘图标不再被折叠（1.2.1）**：启动时把 Windows 11 通知区域的图标设为「始终显示」（`IsPromoted=1` + `SHChangeNotify`），不用再手动从托盘溢出区拖出。
- **受限模式图标外观兜底（1.2.1）**：读不到真实 Windows 桌面度量时使用上次缓存的值；无缓存时回退到与 Windows 一致的实测常量（图标 48、栅格 76.67×98、原点 0,3.33），不会退回旧的偏大 96×104 栅格。
- **启动更快、图标不阻塞启动（1.2.8）**：先出托盘/热键，再加载桌面图层；图标位图缓存到数据目录的 `icon-cache-v1\`，续启动直接读缓存，未命中项在后台提取并回填；看门狗延迟 3 秒启动、托盘图标改用内嵌资源、Windows 图标度量缓存优先。启动阶段可用 `startup-perf.log` 查看（详见 [docs/STARTUP-PERF.md](docs/STARTUP-PERF.md)）；图标显示异常时托盘右键 →「刷新桌面图标」可重建缓存。
- **切换桌面不影响程序运行**：切换时把非当前桌面的窗口隐藏（`ShowWindow(SW_HIDE)`），把目标桌面的窗口恢复显示；进程始终在运行，游戏、编译、下载等任务不会中断。
- **新窗口自动归属**：切换到某桌面后新打开的窗口自动归属当前桌面；带 owner 的对话框跟随主窗口；同一程序的新窗口跟随该程序上一次所在的桌面。
- **全局快捷键**：`Ctrl+Alt+数字` 直接切换桌面，`Ctrl+Alt+方向键` 前后切换，另支持把当前窗口移动到其它桌面。
- **托盘菜单**：桌面列表、前后切换、暂停窗口管理、恢复所有窗口、打开设置、打开数据目录、退出。
- **崩溃恢复看门狗**：主进程异常退出时，由看门狗子进程根据会话日志把被隐藏的窗口恢复显示，避免程序「消失」。
- **安全退出**：正常退出、暂停管理、`Ctrl+Alt+Shift+R` 或托盘「恢复所有窗口」都会把所有被隐藏的窗口还原。
- **单实例 + 多数据目录**：默认单实例（再次启动会唤起已运行实例的设置窗口）；不同 `--data-dir` 可并行运行多个实例，方便开发与测试。

> 完整验证记录（验证环境、命令、测试结果与复现方式）见 [`docs/VERIFICATION.md`](docs/VERIFICATION.md)。

## 2. 快速开始

### 方式一：下载发行版（推荐）

1. 打开 [Releases](../../releases/latest) 页面，下载最新版本的 `MultiDesk-<版本号>.zip`；
2. 解压到任意目录（绿色版，无需安装；可连同 `MultiDesk-data` 配置一起拷走）；
3. 双击 `多桌面助手.lnk`（推荐）或 `启动多桌面助手.bat` 启动；程序启动后驻留**系统托盘**（任务栏右下角的小图标），右键托盘图标可切换桌面、打开设置或退出；
   > 建议从**资源管理器（文件夹）双击**启动以获得完整功能（实时壁纸、隐藏系统桌面图标、原生桌面右键菜单）。若从聊天软件/沙箱里直接打开，程序会自动进入「受限模式回退」（不透明系统壁纸 + 内置右键菜单）。
4. 首次使用建议：打开设置 → 「常规设置」→ 勾选「开机自动启动」，之后开机即自动运行。

> 发行版为绿色单文件程序，不需要安装，复制 `MultiDesk.exe` 到任意目录即可使用。
> 「发行版 zip」由 [publish.ps1](publish.ps1) 生成：包含 `MultiDesk.exe`、`app.ico`、快捷方式/卸载 bat 和 `使用说明.txt`。

> **首次运行遇到 SmartScreen「Windows 已保护你的电脑」怎么办？**
> 这是 Windows 对未签名程序的默认拦截。任选其一：
> 1. 双击发行包里的 `启动多桌面助手.bat`（会先自动解除文件锁定，再正常启动）；
> 2. 双击 `多桌面助手.lnk` 快捷方式（推荐复制到桌面使用）；
> 3. 点「更多信息」→「仍要运行」；
> 4. 右键 `MultiDesk.exe` → 属性 → 勾选「解除锁定」→ 确定后再运行。

> **请从资源管理器/桌面快捷方式启动**（普通权限即可）。如果从聊天窗口、沙箱或受限启动器直接打开，Windows 会以「受限模式」启动本程序，此时实时壁纸、原生右键菜单、窗口隔离会被系统限制；程序会自动弹出「是否以完整权限重新启动」的提示，点「是」并在 UAC 确认即可恢复全部功能，也可以之后右键托盘图标 →「以完整权限重启（推荐）」。

### 方式二：从源码构建运行

```bat
:: 1) 获取源码（在 GitHub 页面点「Code → Download ZIP」解压，或 clone 本仓库地址）

:: 2) 构建并运行（需要系统自带的 .NET Framework 4.8 MSBuild，无需安装 .NET SDK / Visual Studio）

```

或使用 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1          # 构建 Debug
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Release # 构建 Release
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Tests   # 构建并运行单元测试
```

构建输出：`src\bin\Debug\MultiDesk.exe`（或 `src\bin\Release\MultiDesk.exe`），同时会复制一份运行副本到 `src\bin\Run\MultiDesk.exe`（开发时请运行该副本，避免占用编译输出导致下次构建失败）。

发布打包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File publish.ps1
:: 产物：dist\MultiDesk\MultiDesk.exe、dist\MultiDesk\使用说明.txt、dist\MultiDesk-<版本号>.zip
```

### 卸载

- 双击发布包里的 **`卸载多桌面助手.lnk`**（或 `卸载多桌面助手.bat`）；
- 卸载程序会先请求正在运行的 MultiDesk 正常退出（恢复被隐藏的窗口 / 桌面图标），再删除程序文件、桌面与开始菜单快捷方式、开机自启项、Windows 11 托盘图标设置；
- 卸载会同时删除配置与桌面图标数据（MultiDesk-data，不可恢复；如需保留请先备份该文件夹）；
- 安全策略：只删除本程序已知的文件，**不会删除程序目录里的其它文件**；目录只有在变空后才会被删除；
- 如果程序卡死无法正常退出，卸载器会结束进程，并由看门狗恢复被隐藏的窗口/桌面图标。

## 3. 使用说明

### 3.1 桌面与图标

- 程序启动后会显示一个全屏的「桌面图层」窗口，它位于普通窗口下方、系统桌面之上，用来绘制当前桌面的壁纸和图标。
- **单击图标**：选中；**双击图标**：启动对应的文件/文件夹/快捷方式/网址。
- **拖动图标**：按住左键拖动，松手后自动吸附到桌面栅格（与 Windows 桌面一致，先向下、再向右排列）。
- **右键图标**：打开图标菜单（打开 / 打开文件所在位置 / 从本桌面移除 / 取消）。
- **右键桌面空白处**：弹出**程序桌面菜单**，其中「查看」（图标大小/自动排列/显示桌面名称）、「排序方式」、「刷新」、「新建」（文件夹/文本文档）**只作用于当前虚拟桌面**；菜单底部「更多选项…」可打开 Windows 原生桌面菜单（查看/排序/刷新/新建/显示设置/个性化/第三方扩展项）。
- **图标大小/排列**：默认「与 Windows 桌面图标大小/间距一致」（跟随真实桌面的图标大小与网格间距，不同 DPI 缩放下也一致）；也可在设置中取消勾选后自定义 小 32px / 中 48px / 大 64px；勾选「自动排列（网格对齐）」时拖动自动吸附，取消勾选后可自由摆放（可重叠）；「整理图标」「按名称排序」可一键规整。
- **拖入文件**：从资源管理器把文件或文件夹拖到桌面图层上，会添加为当前桌面的图标。
- 图标只记录在你的 MultiDesk 配置里，**不会移动、删除或修改磁盘上的真实文件**。

### 3.2 切换桌面

- 快捷键 `Ctrl+Alt+1` ~ `Ctrl+Alt+9`：切换到第 1~9 个桌面；
- `Ctrl+Alt+←` / `Ctrl+Alt+→`：切换到上一个 / 下一个桌面；
- 托盘菜单 → 点击桌面名称；
- 桌面右键菜单 → 桌面列表 / 上一桌面 / 下一桌面；
- 设置窗口 → 左侧选择桌面 → 「切换到该桌面」。

切换时屏幕中下方会短暂显示桌面名称提示（OSD）。

### 3.3 把窗口移动到其它桌面

- 快捷键 `Ctrl+Alt+Shift+←` / `Ctrl+Alt+Shift+→`：把当前前台窗口移动到上一个 / 下一个桌面；
- 托盘菜单 → 「将当前窗口移到」→ 选择目标桌面；
- 窗口移动到非当前桌面后会立即隐藏，切换回该桌面时自动恢复。

### 3.4 托盘菜单

右键托盘区的 MultiDesk 图标：

| 菜单项 | 说明 |
| --- | --- |
| 桌面列表 | 显示所有桌面及当前桌面（勾选），点击切换 |
| 上一个桌面 / 下一个桌面 | 循环切换 |
| 将当前窗口移到 | 把当前前台窗口移动到某个桌面 |
| 暂停窗口管理 | 暂停时**所有窗口都显示**，不再隐藏/恢复；用于临时排查问题 |
| 恢复所有窗口 | 立即把所有被隐藏的窗口恢复显示 |
| 打开设置 | 打开设置窗口（也可双击托盘图标） |
| 打开数据目录 | 打开配置文件/日志所在目录 |
| 退出多桌面助手 | 恢复所有被隐藏的窗口后退出程序 |

### 3.5 设置窗口

设置窗口分为三个页面：

- **桌面设置**
  - 左侧桌面列表：`＋新建`、`↑上移`、`↓下移`、`删除`、`切换到该桌面`；
  - 桌面名称、是否在右下角显示桌面名称；
  - 壁纸：`跟随当前桌面壁纸（推荐，实时/动态壁纸）` / `图片`（可选择图片文件与填充方式）/ `纯色`（颜色值 `#RRGGBB` 或 `#AARRGGBB`，并附带推荐色块）；
  - 图标外观：`与 Windows 桌面图标大小/间距一致（推荐）`（默认）、自定义图标大小（小 32px / 中 48px / 大 64px）、自动排列（网格对齐）开关、`整理图标`、`按名称排序`；
  - 桌面图标：`添加文件…`、`添加文件夹…`、列表内每项支持「打开位置」/「移除」，也支持从资源管理器直接拖入列表。
- **常规设置**
  - 开机自动启动（写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）；
  - 暂停窗口管理 / 立即恢复所有窗口；
  - 快捷键说明、数据目录（可打开）；
  - 退出程序。
- **帮助与说明**：使用说明、注意事项、版本信息。

### 3.6 快捷键一览

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Alt+1` ~ `Ctrl+Alt+9` | 切换到第 1~9 个桌面 |
| `Ctrl+Alt+←` | 上一个桌面 |
| `Ctrl+Alt+→` | 下一个桌面 |
| `Ctrl+Alt+Shift+←` | 把当前窗口移到上一个桌面 |
| `Ctrl+Alt+Shift+→` | 把当前窗口移到下一个桌面 |
| `Ctrl+Alt+S` | 打开设置窗口 |
| `Ctrl+Alt+Shift+R` | 恢复所有被隐藏的窗口（紧急恢复） |

> 如果快捷键被其它软件占用，程序会在日志中记录注册失败项；可在托盘菜单操作，或关闭占用快捷键的软件后重启 MultiDesk。

## 4. 实现原理简述

### 4.1 桌面图层与窗口隔离

- MultiDesk 启动后创建一个覆盖整块虚拟屏幕、**始终置底（不进任务栏、不抢焦点）** 的 WPF 图层窗口，用于绘制当前桌面的壁纸、图标和右键菜单。
- 引擎定时（约 400ms）枚举所有顶层窗口，维护「窗口 → 桌面」映射：
  - 当前桌面的窗口正常显示；其它桌面的窗口调用 `ShowWindow(SW_HIDE)` 隐藏；
  - 切换桌面时隐藏旧桌面窗口、恢复目标桌面窗口，并尽量恢复窗口原来的最小化/最大化与前台状态；
  - 新窗口默认归属当前桌面；有 owner 的对话框跟随拥有者；同进程的新窗口跟随该进程最近所在桌面。
- 全程**不结束任何进程**，只是隐藏窗口，因此切换桌面不影响程序继续运行。

### 4.2 崩溃恢复（看门狗）

- 每当引擎隐藏窗口时，会把被隐藏窗口的句柄、进程 ID、进程启动时间、桌面归属等写入会话日志 `session.json`（位于数据目录）。
- 正常退出时先恢复所有窗口并清空会话日志。
- 如果不是正常退出（崩溃/被强杀），由随主进程启动的看门狗子进程（`--watchdog`）在主进程退出后读取会话日志，校验句柄与进程 ID 后把窗口恢复显示。
- 1.2.8 起看门狗改为**启动完成 3 秒后**再拉起（避免登录瞬间第二个 WPF 进程和主进程争抢磁盘/CPU）；这几秒内若主进程被强杀，桌面图标 marker 会在下次启动时恢复，窗口恢复保护的缺口只有数秒。
- 会话日志带「本次开机」标记，重启电脑后不会误恢复上一次开机的旧句柄。

### 4.3 配置与数据

程序会自动选择一个**当前用户确实可写**的数据目录，按以下顺序探测（第一个可写的即被使用）：

1. **程序所在目录下的 `MultiDesk-data\`**（绿色便携模式，推荐：把 exe 复制到任意目录即可连同配置一起带走）；
2. `%LOCALAPPDATA%\MultiDesk\`
3. `%APPDATA%\MultiDesk\`
4. `%TEMP%\MultiDesk\`
5. `%USERPROFILE%\MultiDesk\`

> 说明：某些安全软件、企业策略或受限启动环境可能禁止程序写入 AppData；自动回退可以保证程序仍能正常启动。你也可以用 `--data-dir=<目录>` 强制指定数据目录（设置窗口「常规设置」里能看到实际使用的目录并打开它）。

| 文件 | 说明 |
| --- | --- |
| `config.json` | 桌面、图标、壁纸、选项等全部配置（UTF-8 JSON） |
| `config.json.bak` | 上一次保存的备份（配置损坏时自动回退） |
| `app.log` | 启动/切换/错误等运行日志 |
| `startup-perf.log` | 启动阶段计时（1.2.8 起；每次启动一组，含系统 uptime，用于排查开机自启慢） |
| `icon-cache-v1\` | 桌面图标位图磁盘缓存（1.2.8 起；可安全删除，删除后下次启动会重新提取） |
| `crash.log` | 崩溃日志（如有） |
| `session.json` | 会话日志（被隐藏窗口，用于崩溃恢复；正常情况下为空/不存在） |

配置损坏时可删除 `config.json` 后重启（会自动生成默认配置）；也可以把 `config.json.bak` 改名为 `config.json` 恢复上一次配置。

### 4.4 实时壁纸与原生桌面右键菜单（1.1.0）

- 桌面图层是一个覆盖全屏的**透明 WPF 窗口**。壁纸模式为「跟随当前桌面壁纸」时，图层不绘制背景，直接把系统真实桌面透出：Windows 壁纸、Wallpaper Engine 等壁纸软件渲染的动态壁纸都会实时可见。
- 程序运行期间会隐藏系统真实桌面图标（`SysListView32`），避免与程序自己的图标重复；正常退出/崩溃时通过 marker 文件与看门狗恢复。如果用户本来就关闭了「显示桌面图标」，则不会改动。
- 桌面空白处右键弹出程序自绘的桌面菜单：「查看/排序方式/刷新/新建」由程序自己处理，只作用于当前虚拟桌面（不会再改动真实桌面图标）；菜单末尾的「更多选项…」会转发 `WM_CONTEXTMENU` 给系统桌面视图（`SHELLDLL_DefView`），用于调出**真正的 Windows 桌面右键菜单**（含第三方 shell 扩展项）。图标右键仍是程序自绘菜单。
- 「新建」产生的文件夹/文本文档保存在数据目录的 `DesktopItems\` 中，只作为当前桌面的图标，不会创建到真实系统桌面。

### 4.5 受限启动回退（低完整性）

从聊天软件、沙箱、受限启动器等环境启动时，进程可能是低完整性（Low IL）。Windows 的 UIPI 会禁止它操作资源管理器（Medium）的桌面窗口，此时程序会自动检测并回退：

- 「跟随当前桌面壁纸」改为绘制系统壁纸图片（不透明，避免真实桌面图标重复显示）；
- 桌面空白处右键改为程序内置菜单（刷新 / 整理图标 / 切换桌面 / 桌面列表 / 打开设置 / 恢复所有窗口）。

> 程序启动时会检测自己是否运行在受限模式：如果是，会弹出提示「是否以完整权限重新启动」，点「是」并在 UAC 中确认即可恢复完整功能；运行中也可以右键托盘图标 →「以完整权限重启（推荐）」。平时建议从**资源管理器/桌面快捷方式**启动（普通权限即可），以获得实时壁纸、隐藏系统图标和原生桌面右键菜单等完整功能。

## 7. 构建方法与测试

环境要求：

- Windows 10 / Windows 11；
- .NET Framework 4.8（系统自带）；
- 使用系统自带 MSBuild：`%WINDIR%\Microsoft.NET\Framework\v4.0.30319\MSBuild.exe`（**无需安装 .NET SDK / Visual Studio**）。

命令：

```powershell
# 构建 Debug（输出 src\bin\Debug\MultiDesk.exe，并复制运行副本 src\bin\Run\MultiDesk.exe）
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1

# 构建 Release
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Release

# 构建并运行单元测试（输出 Total/Passed/Failed，失败时退出码非 0）
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Tests

# 发布打包（Release 构建 + dist\MultiDesk + zip）
powershell -NoProfile -ExecutionPolicy Bypass -File publish.ps1
```

说明：

- `build.ps1` 自带构建锁（多终端/多 agent 同时构建会排队），并会把 `.cs` 文件统一转为 UTF-8 with BOM，保证旧版 C# 编译器正确读取中文；
- 单元测试位于 `tests/`，使用自写的最小测试运行器（用例注册 + 断言 + PASS/FAIL + 汇总 + 失败退出码），**不依赖任何第三方 NuGet 包**，也无需联网；
- E2E / 截图辅助脚本位于 `scripts/`，用法见 `docs/VERIFICATION.md`；
- **持续集成**：GitHub Actions 在每次 push / Pull Request 时自动执行 `build.ps1 -Release -Tests`（见 [`.github/workflows/build.yml`](.github/workflows/build.yml)），构建或测试失败会直接标红；
- 整理仓库时的验证结果：Release 构建成功，单元测试 **134/134 通过**；`--selftest` / `--ui-only` 端到端验证记录见 [`docs/VERIFICATION.md`](docs/VERIFICATION.md)；1.2.8 启动性能验证见 [`docs/STARTUP-PERF.md`](docs/STARTUP-PERF.md)。

## 8. 常见问题（FAQ）

**Q1：第一次启动后，桌面图标好像没有变化？**
A：首次运行时会把系统桌面上已有的图标导入到当前桌面（「工作桌面」），所以你看到的是导入后的图标；如果当前是 `--ui-only` 模式，则不导入、也不接管真实窗口。若想重新导入：退出程序，删除数据目录下的 `config.json` 后重启。

**Q2：为什么真实桌面上的图标被 MultiDesk 的图标「盖住」了？**
A：桌面图层是不透明窗口，位于系统桌面之上，用来显示每个桌面独立的图标与壁纸；系统真实桌面图标被图层覆盖属于预期行为（图标已导入到 MultiDesk 配置中）。退出 MultiDesk 后即可看到系统真实桌面。

**Q3：切换桌面后，某个程序的窗口没有隐藏/恢复？**
A：以下窗口无法被管理：以管理员权限运行的程序（权限隔离 UIPI）、部分独占全屏的游戏、系统关键窗口/UWP 外壳窗口、带特殊 cloaked 状态的窗口。可以先尝试：托盘 →「暂停窗口管理」再恢复，或退出重启程序。

**Q4：快捷键没反应？**
A：`Ctrl+Alt+1..9` 等快捷键是全局热键，可能被其它软件（输入法、显卡驱动、游戏加速器等）占用。程序日志 `%APPDATA%\MultiDesk\app.log` 会记录哪些快捷键注册失败；关闭占用软件后重启 MultiDesk。也可以始终使用托盘菜单切换。

**Q5：程序崩溃或被强杀后，被隐藏的窗口怎么办？**
A：正常情况下看门狗子进程会在主进程退出后自动恢复所有被隐藏的窗口。如果仍未恢复，重新启动 MultiDesk 会自动执行上一次会话的恢复；也可以手动用 `Ctrl+Alt+Shift+R` 或托盘/设置里的「恢复所有窗口」。

**Q6：怎么彻底退出程序？**
A：托盘图标右键 →「退出多桌面助手」，或在设置 →「常规设置」→「退出程序」。退出时会恢复所有被隐藏的窗口。

**Q7：杀毒软件/Windows Defender/SmartScreen 提示风险？**
A：程序会枚举窗口、隐藏/显示其它程序的窗口，并写入开机启动注册表项，这些行为可能触发启发式告警。程序不联网、不修改系统文件、不删除任何用户文件；如不放心可在杀毒软件中将其加入信任。另外本程序**未做代码签名**，首次运行可能触发 SmartScreen「Windows 已保护你的电脑 / 未知发布者」。解决办法：
1. 双击发行包里的 `启动多桌面助手.bat`（自动 `Unblock-File` 后启动，最简单）；
2. 双击 `多桌面助手.lnk`（推荐复制到桌面）；
3. 点「更多信息」→「仍要运行」；
4. 右键 `MultiDesk.exe` → 属性 → 勾选「解除锁定」→ 确定后再运行。
若从聊天软件/沙箱直接打开，程序会检测到受限模式并提示「以完整权限重新启动」，点「是」并在 UAC 中确认即可。
**推荐直接双击发布包里的 `多桌面助手.lnk` 或 `启动多桌面助手.bat`**：它们通过 Microsoft 签名的 PowerShell 以普通权限启动程序（不经过 SmartScreen 检查、也不会提权），可以完全避免上述提示。

**Q8：多个桌面实例同时运行会怎样？**
A：默认同一数据目录只允许一个实例（重复启动会唤起已有实例的设置窗口）。不同 `--data-dir` 的实例可以共存，但**全局快捷键只有第一个实例能注册**，多实例同时运行时建议只用托盘/设置切换。

**Q9：配置文件损坏了怎么办？**
A：程序会自动尝试 `config.json.bak` 备份，仍失败则回退到默认配置（不会崩溃）。也可以手动删除/替换数据目录下的 `config.json`。

**Q11：程序窗口在前台时，为什么截图/其它软件的快捷键失效？**
A：如果 MultiDesk 是以**管理员权限**启动的，根据 Windows 的 UIPI 安全机制，普通权限的截图/快捷键工具（Snipaste、QQ/微信截图等）的热键在其窗口前台时会被系统屏蔽。发布包里的快捷方式/`启动多桌面助手.bat` 已改为**普通权限**启动（窗口和普通程序同级，不会再屏蔽其它软件快捷键）：请用这些方式启动，不要右键"以管理员身份运行"。如果已经以管理员身份运行，退出后改用快捷方式重新启动即可。

**Q10：勾选「开机自动启动」失败/不生效？**
A：开机自启通过写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 实现。部分企业组策略、安全软件或系统优化工具会禁止写入该注册表项，此时设置会失败（程序会提示）。可改用「任务计划程序」或「启动」文件夹放置快捷方式实现开机启动。

**Q12：开机自启后，为什么托盘/桌面图标要过一会儿才出现？**
A：1.2.8 已把托盘和热键放到启动最前面（通常 1 秒内出现），桌面图标会先显示占位图、再在后台逐个补齐（续启动读磁盘缓存后基本瞬间完成）。第一次启动或删除过 `icon-cache-v1\` 后，需要重新调用 Shell 提取图标，冷机下会多花 1~3 秒补图标，但**不再阻塞启动和托盘出现**。若想确认每次启动各阶段耗时，可查看数据目录下的 `startup-perf.log`（说明见 [docs/STARTUP-PERF.md](docs/STARTUP-PERF.md)）。

## 9. 限制与注意事项

1. **权限**：以管理员权限运行的程序窗口无法被普通权限的 MultiDesk 隐藏/恢复（UIPI）；如需管理管理员程序，请以管理员身份运行 MultiDesk。
2. **全屏游戏**：部分使用独占全屏（DirectX exclusive fullscreen）的游戏窗口在切换桌面时可能闪烁或无法正常隐藏/恢复，建议使用无边框窗口模式。
3. **真实桌面图标被覆盖**：桌面图层会覆盖系统真实桌面图标（这是独立桌面图标功能的前提），程序运行期间属于预期行为，退出程序即恢复真实桌面。
4. **退出/崩溃恢复**：请通过托盘/设置正常退出，或使用 `Ctrl+Alt+Shift+R` 紧急恢复；直接结束进程/崩溃时由看门狗根据会话日志恢复被隐藏的窗口（重启电脑后不会误恢复旧句柄）。
5. **多显示器**：桌面图标按主显示器工作区排版；壁纸按整块虚拟屏幕绘制。
6. **分辨率变化**：程序启动时记录屏幕布局，运行中修改分辨率/缩放后建议重启程序以获得最佳图标布局。
7. **系统重启**：会话日志带开机标记，电脑重启后不会误恢复旧句柄；重启后请正常启动程序。
8. **快捷键冲突**：全局热键可能被其它软件占用（见 FAQ Q4）；多实例运行时只有第一个实例能注册全局热键。
9. **首次运行**：会导入系统桌面图标并写入配置；程序不会移动、删除或修改任何磁盘文件。
10. **未签名程序**：`MultiDesk.exe` 未做代码签名，首次运行可能触发 Windows SmartScreen「未知发布者」/「打开文件-安全警告」提示（系统策略行为，详见 FAQ Q7）。
11. **开机自启可能被策略禁用**：部分企业组策略/安全软件禁止写入 `HKCU\...\Run`，此时「开机自动启动」会失败（详见 FAQ Q10）。
12. **壁纸**：支持「跟随当前桌面壁纸（可实时透出 Wallpaper Engine 等动态壁纸，需从资源管理器正常启动）」「图片」「纯色」；受限启动模式下回退为静态系统壁纸图片。
13. **受限启动（低完整性/沙箱）**：从聊天软件、沙箱或受限启动器启动时，系统桌面图标隐藏和原生桌面菜单不可用，程序会自动回退（不透明系统壁纸 + 内置右键菜单）。首次会提示「以完整权限重新启动」；若选择「否」（不再提示）且未关闭「受限启动时自动以完整权限重启」（1.2.1 默认开启），下次受限启动会直接弹 Windows UAC 尝试以完整权限重启，取消 UAC 则静默回退受限模式。设置 →「常规设置」可重新开启受限提示或关闭自动提权。平时建议从资源管理器/桌面快捷方式启动。
14. **图标还原范围**：仅管理普通顶层窗口；系统关键窗口、UWP 外壳窗口、带 cloaked 状态的窗口会被跳过（避免误操作）。
